# G32R5xx SDK

Official G32R5xx software development kit from Geehy Semiconductor.

## Current version

- SDK version: V1.1.0
- Supported device: G32R501
- Official package date: May 7, 2025
- Release notes date: April 15, 2025
- Official download: [G32R501_SDK_V1.1.0.zip](https://global.geehy.com/uploads/tool/G32R501_SDK_V1.1.0.zip)

## Repository contents

- `boards`: board support files
- `device_support`: device-specific startup, linker, debug, and tool support files
- `docs`: SDK documentation
- `driverlib`: peripheral driver libraries
- `examples`: peripheral and application examples
- `kernel`: kernel-related components
- `libraries`: supporting libraries and middleware components
- `package`: device support package files
- `utilities`: supporting utilities
- `Release Notes.txt`: official SDK release notes
